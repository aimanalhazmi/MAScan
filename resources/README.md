# Scenarios 

- The repo has three scenarios that were made ready for testing. They encompass 3 different companies (Evonik, Volkswagen, BioNTech) with their different environments and needs. 
- Each company has a ready query that can be used to standarize the tests and runs and a set of relevant data in form of pdfs and markdown files that can be used as input for the RAG system. 
- Those were either downloaded directly if available or parsed from HTML articles to MD files using firecrawl parser tools.
